# Скрипт Windows и залипание Shift

`layout.ahk` — копия пользовательского скрипта AutoHotkey v2 из автозагрузки.
Сочетания Shift+F13/F14 переключают язык, Shift+F15…F18 печатают знаки.

Исправление добавляет `InstallKeybdHook`, чтобы AutoHotkey отслеживал реальное
состояние модификаторов при их временном отпускании и восстановлении в `Send`.
`KeyHistory 0` отключает хранение истории клавиш. Сочетания и печатаемые символы
не изменены. Перепрошивка клавиатуры для этого изменения не нужна.

Это мера для повышения надёжности отслеживания состояния в скрипте,
но связь с конкретным случаем залипания пока не установлена: за минуту записи
залипание не воспроизвелось. Синтаксис проверен установленным AutoHotkey через
`/ErrorStdOut /Validate`, без запуска обработчиков.

Источник: [AutoHotkey: InstallKeybdHook](https://www.autohotkey.com/docs/v2/lib/InstallKeybdHook.htm),
раздел Remarks о восстановлении состояния модификаторов после `Send`.

Для установки заменить `layout.ahk` в папке автозагрузки Windows этой копией,
предварительно сохранив прежний файл, затем перезапустить именно этот скрипт.
Не запускать одновременно старую и новую копии из разных папок.

`../capture-shift.ps1` записывает только Shift/F13/F14 и состояние модификаторов,
а остальные нажатия лишь подсчитывает без сохранения кодов. Для получения событий
нужно запускать его в интерактивной сессии пользователя, а не в изолированной
учётной записи Codex. Без запроса пользователя повторный тест не запускать.
