# Рабочее состояние: 21 октября 2026

Пользователь подтвердил совместную работу обеих половин через донгл и работу
трекбола. Проверенный комплект сохранён в `firmwares/known-good/2026-10-21/`:

- `charybdis_dongle.uf2` — донгл с USB-журналом и удвоенной скоростью указателя;
  исходный файл: `firmwares/diagnostics/charybdis_dongle_fast_debug.uf2`.
- `charybdis_left.uf2` — левая половина.
- `charybdis_right.uf2` — правая половина с PMW3610.
- `settings_reset.uf2` — сброс настроек с работающим стиранием NVS.

`manifest.json` содержит SHA256 файлов, версии зависимостей и имя платы.
Рядом сохранены фактические конфигурации сборки всех четырёх файлов.
Обычная сборка не перезаписывает этот архив.

Для возврата прошить соответствующие три основных UF2 из архива. Сброс обычно
не нужен: он удаляет сохранённые настройки и Bluetooth-сопряжения. Если требуется
полное новое сопряжение, сначала прошить `settings_reset.uf2` во все три
контроллера, дать каждому запуститься, затем прошить основные UF2.

Левая первоначально не подключалась. После её перезапуска журнал донгла
подтвердил соединение, уровень безопасности 2 и события клавиш; затем пользователь
подтвердил работу обеих половин одновременно. Точная причина первого отказа
не установлена.

Важные особенности этого состояния:

- Плата: `nice_nano@2.0.0/nrf52840/zmk`; базовый `nice_nano` не обеспечивает
  нужные настройки NVS и узел питания трекбола P0.13.
- Донгл — центральное устройство на две половины; обе половины — периферийные.
- Правая использует отдельное имя shield `charybdis_dongle_right`, чтобы
  исключить конфликт с конфигурацией Bluetooth-версии.
- Датчик физически существует только справа; донгл принимает его события по BLE.
- Обычная скорость указателя теперь `2/5`; медленный режим и прокрутка — `1/16`.
- USB-журнал включён в архивном донгле. Обычная локальная сборка его отключает.
- Раскладка пользователя сохранена. `PercentPrint` пока связан с `&none`:
  печать процентов в проверенном комплекте отключена.
- Bluetooth-версия без донгла, расход аккумуляторов и пробуждение трекболом
  этим подтверждением не проверены.

В `config/west.yml` пока указаны ветки `main`. Для точного восстановления
зависимостей нужно использовать SHA из архивного `manifest.json`; повторный
`west update` по веткам может получить другой код.

Обычная сборка трёх файлов:

```powershell
docker compose -f local-build/docker-compose.yml run --rm builder bash ./local-build/build_single.sh qwerty dongle
```

USB-журнал архивного донгла:

```powershell
powershell -ExecutionPolicy Bypass -File .\local-build\capture-usb-log.ps1
```

При нескольких COM-портах передать `-Port COM13` с актуальным номером порта.
